# Jianghu lettering font

`jianghu-letters.ttf` is a glyph subset of **Ma Shan Zheng**, Copyright 2018 The Ma Shan Zheng Project Authors. Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/mashanzheng).

Distributed under the accompanying `OFL-MaShanZheng.txt`. Only the characters used by the homepage lettering and small flourishes are included; normal page text uses the existing fonts. Hinting was removed to keep this decoration small. No runtime Google Fonts request is used.

Current subset: 39 unique characters, 25,724 bytes. It includes the hero lettering and the lower-page headings 札记、习得、行迹、问剑、未完. Font preload and CSS use the same versioned URL.

Upstream font Git blob: `11bbfb9867d70612158229d037e7a5f622bd0e38` (5,857,936 bytes before subsetting).

If the Chinese lettering changes, regenerate the subset to include the new characters. The CSS has KaiTi / STKaiti / serif fallbacks when the asset is unavailable.
